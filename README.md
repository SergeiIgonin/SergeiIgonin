## Python QA Automation Engineer

Инженер по автоматизации тестирования с опытом проектирования и развития тестовых фреймворков для платформы виртуализации и стриминговых сервисов. Специализация — API-автоматизация (REST) и UI-проекты на Playwright.


**Мой опыт и фокус:**
- 🐍 Пишу автотесты на **Python** (Pytest, Requests, Playwright, Selenium).
- 🏗 Проектирую архитектуру тестовых фреймворков (Page Object Model, двухслойная архитектура).
- 🚀 Настраиваю пайплайны **CI/CD** (GitLab CI, GitHub Actions, Jenkins).
- 📺 Ранее тестировал видео-стриминговые платформы (HLS, Smart TV, Mobile) в Триколор.
- 🤖 Активно использую **ИИ-инструменты** (LLM) для генерации и рефакторинга автотестов.

**Мой стек:**
